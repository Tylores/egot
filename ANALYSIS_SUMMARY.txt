================================================================================
                         IMPLEMENTATION RULES
================================================================================

RULE 1: Header Order
--------
ALWAYS follow this order:
  1. w.Header().Set("location", ...) [if needed]
  2. w.Header().Set("Content-Type", "application/sep+xml") [if body]
  3. w.WriteHeader(http.StatusXXX)
  4. xml.NewEncoder(w).Encode(&sep.Struct{})

RULE 2: Status Codes
--------
Use these exact Go constants:
  - 200 OK:                    http.StatusOK
  - 201 Created:               http.StatusCreated
  - 400 Bad Request:           http.StatusBadRequest
  - 405 Method Not Allowed:    http.StatusMethodNotAllowed

RULE 3: Response Bodies
--------
- GET/DELETE/POST-list: Always encode proper struct
- HEAD: Never encode anything
- Error methods (405/400): Never encode body
- All non-error bodies: Set Content-Type = "application/sep+xml"

RULE 4: Location Header
--------
Only for successful POST to list resources:
  w.Header().Set("location", fmt.Sprintf("/tp/%d", resourceID))
  
Path format: /SERVICE/{ID}
  - /tp/{id}      for TariffProfile
  - /bill/{id}    for Bill
  - etc.

RULE 5: Error Handling
--------
If WriteHeader already called, can't call it again.
Use early returns:

  if err != nil {
    log.Printf("error: %v", err)
    return  // No WriteHeader call here!
  }
