MAKE COMMANDS AVAILABLE:
================================================================================

Test Execution:
  make test              - Run all tests
  make test-unit         - Unit tests only (SHORT FORM - DEFAULT FOR DEV)
  make test-integration  - Integration tests
  make test-verbose      - All tests with verbose output and race detector
  make test-coverage     - Run tests and generate HTML coverage report
  make test-short        - Short tests only
  make test-race         - Race detector only (finds data races)

Targeted Testing:
  make test-package PKG=./internal/Bill                    - Specific package
  make test-service SERVICE=core                          - Specific service
  make test-service SERVICE=crawler                       - (8 services available)
  make test-service SERVICE=flowreservation
  make test-service SERVICE=operator
